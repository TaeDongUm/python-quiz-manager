# 기능 단위 체크리스트

## 1. 프로그램 실행 및 메뉴

* [x] 프로그램을 실행하면 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료 메뉴가 출력된다.
* [x] 사용자가 메뉴 번호를 입력하면 선택한 기능이 실행된다.
* [x] 기능 실행이 끝나면 다시 메인 메뉴로 돌아간다.
* [x] 종료 메뉴를 선택하면 프로그램이 정상적으로 종료된다.

## 2. 입력 및 예외 처리

* [x] 입력값의 앞뒤 공백을 제거한 후 처리한다.
* [ ] 빈 값, 문자가 포함된 값, 허용 범위를 벗어난 숫자를 입력하면 안내 메시지를 출력하고 다시 입력받는다.
* [ ] 메뉴 번호와 퀴즈 정답 번호의 입력 범위를 각각 검사한다.
* [ ] 실행 중 `Ctrl+C` 또는 입력 스트림 종료가 발생하면 가능한 데이터를 저장하고 안전하게 종료한다.
* [ ] 데이터 파일이 없거나 손상되어도 프로그램을 실행할 수 있다.

## 3. 기본 퀴즈 제공

* [ ] 직접 선택한 하나의 주제로 기본 퀴즈를 5개 이상 제공한다.
* [ ] 각 퀴즈는 문제, 선택지 4개, 정답 번호를 포함한다.
* [ ] 저장된 데이터가 없는 첫 실행에서는 기본 퀴즈를 불러온다.

## 4. 퀴즈 풀기

* [ ] 저장된 퀴즈의 문제와 선택지 4개를 사용자에게 순서대로 출력한다.
* [ ] 사용자가 1~4 사이의 정답 번호를 입력할 수 있다.
* [ ] 정답 입력 후 정답 또는 오답 여부를 알려준다.
* [ ] 모든 퀴즈를 풀면 맞힌 문제 수와 최종 점수를 출력한다.
* [ ] 등록된 퀴즈가 없는 경우 안내 메시지를 출력한다.
* [ ] 퀴즈 풀기 기능은 별도의 Git 브랜치에서 개발한 후 `main` 브랜치에 병합한다.

## 5. 퀴즈 추가

* [ ] 사용자가 새로운 문제와 선택지 4개를 입력할 수 있다.
* [ ] 사용자가 1~4 사이의 정답 번호를 입력할 수 있다.
* [ ] 문제, 선택지 또는 정답 번호가 잘못 입력되면 안내 후 다시 입력받는다.
* [ ] 입력한 내용으로 새로운 퀴즈를 생성하여 기존 퀴즈 목록에 추가한다.
* [ ] 추가한 퀴즈를 즉시 데이터 파일에 저장한다.

## 6. 퀴즈 목록 확인

* [ ] 현재 등록된 퀴즈의 전체 개수를 확인할 수 있다.
* [ ] 등록된 퀴즈의 번호와 문제 내용을 목록으로 확인할 수 있다.
* [ ] 등록된 퀴즈가 없는 경우 안내 메시지를 출력한다.
* [ ] 사용자가 추가한 퀴즈도 목록에 함께 출력된다.

## 7. 점수 기록 및 확인

* [ ] 퀴즈를 완료하면 획득한 점수를 계산한다.
* [ ] 획득한 점수가 기존 최고 점수보다 높으면 최고 점수를 갱신한다.
* [ ] 점수 확인 메뉴에서 저장된 최고 점수를 확인할 수 있다.
* [ ] 아직 퀴즈를 풀지 않은 경우 안내 메시지를 출력한다.
* [ ] 프로그램을 종료하고 다시 실행해도 최고 점수가 유지된다.

## 8. 데이터 저장 및 불러오기

* [ ] 퀴즈 목록과 최고 점수를 프로젝트 루트의 `state.json`에 저장한다.
* [ ] `state.json`을 UTF-8 인코딩으로 읽고 저장한다.
* [ ] 프로그램을 다시 실행하면 이전에 추가한 퀴즈와 최고 점수를 불러온다.
* [ ] `state.json`이 없는 경우 기본 퀴즈 데이터로 시작한다.
* [ ] `state.json`이 손상된 경우 안내 메시지를 출력하고 기본 데이터로 복구하거나 초기화한다.
* [ ] 파일 읽기 또는 쓰기 오류가 발생해도 프로그램이 비정상적으로 종료되지 않는다.
